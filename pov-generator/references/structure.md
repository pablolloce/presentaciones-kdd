# POV structure

Use a problem -> analysis -> view -> capabilities arc.

## 1. Cover
- topic
- subtitle: Our View / Nuestra visión

## 2. Context
- why the topic matters now
- crisis, market, regulatory, or strategic backdrop

## 3. Key challenges
- 3-6 challenge areas
- explain why they are hard in practice

## 4. Our view
- target model / framework / thesis
- what a better future state looks like
- roadmap or maturity path when useful

## 5. Capabilities / implications
- what this means for clients
- where nfq can help
- practical next actions

## 6. Annex (optional)
- regulatory detail
- case references
- deeper frameworks

## Working rule
A POV earns the right to have a point of view only after showing that it understands the problem deeply.
