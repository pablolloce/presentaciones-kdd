# Proposal structure

## 1. Cover
- proposal title
- client name
- date / scope subtitle

## 2. Legal / framing
- confidentiality
- assumptions on usage / NDA references if relevant

## 3. Context
- client situation
- key pain points
- project objectives

## 4. Why nfq
- relevant credentials
- differentiators
- fit for the engagement

## 5. Diagnosis / vision
- what problem space we see
- initial framing / target approach

## 6. Methodology and plan
- phases
- workstreams
- deliverables
- governance
- timeline

## 7. Team and commercials
- team shape / dedication
- pricing approach
- payment assumptions
- caveats

## 8. Annex
- credentials
- capability pages
- CV summaries
- accelerators and tools

## Working rule
Always draft assumptions before writing commercials. A beautiful lie is still a lie.
